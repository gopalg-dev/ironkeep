# Plates web app: feature inventory for the offline port

Source repo: `workout_plan_v3` at commit `7d275f1` (2026-10-21). Where the old context files and
the code disagreed, the code won. This file is the reference for "what the web app does today".
The mobile requirements in `00-requirements.md` decide what of it comes along.

Two facts that shape the port:
- There is no import of past sessions or logs in the web app. The only file import is the plan template.
- Exercise pictures load from GitHub at run time (314 JPGs). An offline app has to bundle them.

---

## 1. Screens

**App shell** (`src/routes/_app.tsx`):
- Before every app screen: signed out goes to `/how-it-works` or `/login`; signed in but `setupDone` false goes to `/setup`.
- Data: `getContentFn()` (split templates plus library rows, no cues), read through `ContentProvider` / `useContent()`.
- Navigation: phones get a bottom `TabBar` with Today `/`, Plan `/plan`, Stats `/stats`, plus a slim header with a menu button that opens the sidebar as a sheet. From 768px: a collapsible sidebar with the same three, plus Report, Library and How it works.
- Account menu (sidebar footer): Settings, Look (`LookRadioGroup`), Send feedback, Install app, Sign out.
- `?exercise=<library id>` on any screen opens `ExerciseDialog` (wraps `LibraryDetail`): two pictures in a carousel, numbered cues, "Works: ...", muscle, equipment, level, Previous / Next through the list the page publishes via `useExerciseList`. `ExerciseThumb` on every exercise row links here.

### `/setup`

Five steps, one per screen, progress "N of 5", Enter moves on, Back. `?step=split` opens on step 2.

| Step                              | What it asks                                                                                                                                                                                                                                               |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0 Units                           | ToggleGroup Kilograms / Pounds                                                                                                                                                                                                                             |
| 1 Which split?                    | `SplitPicker`: the 9 templates with fit line, program name (`SPLIT_SOURCES`) and `WeekShape`; "Your own" (`OwnDaysEditor`, 2 to 6 day kinds, default upper, lower, upper, lower); `EmptyDaysOption` tick "Start with empty days"; a warning when switching |
| 2 What do you weigh today?        | `NumberField` (step 0.5 kg / 1 lb), Gain / Hold / Cut toggle (starts on gain), Skip button                                                                                                                                                                 |
| 3 How long have you been lifting? | Radio: Under a year / A year or more                                                                                                                                                                                                                       |
| 4 How should the weight go up?    | `ProgressionPicker`, default `double`                                                                                                                                                                                                                      |

Finish ("Start training"): `saveSettingsFn({ units, trainingAge, progression, goal, setupDone: true, bodyweight })` (stamps `joinedAt` once), then `createCustomPlanFn({ types, empty })` or `applySplitFn({ split, empty })`, then `logBodyweightFn` for today on first run or when the number changed.

Logic: `defaultProgression`, `templateOf`, `GOAL_OPTIONS`, `dayKey`.

### `/` Today

Loader `getTodayFn` -> `repo.getTodayData`. `?zen=1` keeps Zen mode across a reload.

**A. Next up (no session running), `NextUpView`:**
- Header: date line, `DayIcon`, day name as title. Rolling: `nextDayId(plan.days, rollingCursor(lastFinished, settings.rolledPast))`. Weekday: `weekdayView` gives "Rest day", "Done for today", "Next: X, tomorrow / <weekday>".
- Streak top right: flame plus "N week(s)" (`weeklyStreakOf`).
- Summary line "N exercises, M sets" (`plannedSetsFor`, caps at 3 under a year). Empty day: "No lifts yet."
- `AlertDeck`: one card at a time, swipeable, with previous / next and dots. Each card has a dismiss (`dismissAlertFn`) and an action link: stall "Swap on Plan", weight "See weight", review "See report".
- Weigh-in / tape reminder from `nudgeFor`: offers `LogBodyweightDialog` or `LogMeasurementsDialog`, and "Not now" (`dismissNudgeFn`).
- The day's lifts: thumbnail, name, "sets x range".
- Buttons: Start <day> (or "Add lifts on Plan" on an empty day); Pick another day (drawer listing every day with "Done today / yesterday / N days ago" via `lastDoneAt`, `relativeDay`, and Start each; called "Pick a day" on a rest day); Skip or done (rolling only, more than one day): `SkipDialog` then `skipDayFn`.

**B. Active workout (`ActiveWorkout`):**
- Screen wake lock while active unless `keepAwake === false`.
- `SessionTitle`: "Started 6:05 PM · 42 min" (`activeMs`, `elapsedLabel`, ticks every 15 s), Pause / Resume (`pauseWorkoutFn`), `ZenButton`, and a "Session options" menu: Change session (drawer of other days, "Switching drops the N sets logged so far.", `startWorkoutFn`) and Discard workout (`DiscardDialog`, `discardWorkoutFn`).
- `SessionExercises`: accordion, one `ExerciseRow` open at a time. Each row: thumbnail, name, "sets x range", "done/total", check when all done; the `hint`; per set a weight `NumberField` (step `incrementFor(units, equipment, steps, plateLoaded)`), reps or seconds (step 5 for holds), a done Toggle. Blank fields show placeholders from `targetFor` (the set's `suggested` target, else the nearest earlier filled set). A weight set cannot be ticked without a weight above zero (`canComplete`); ticking fills blanks (`completeSet`). After the last set of a weight lift: "Reps left" toggle 0 / 1-2 / 3+ (`LEFT_OPTIONS`, stored as `left` 0, 1 or 3). Buttons: "+1 set to plan" when `rampOffer` (`acceptRampFn`), Add a set, Remove the last set, Swap.
- Saving: each tick saves at once; a stepped number saves 500 ms later (`saveSetsFn`).
- Auto-advance: ticking the last set opens the next exercise; a weight lift waits for the reps-left answer.
- `SwapLiftPanel` (`EditorPanel`: Dialog from 768px, Drawer below): the plan line's alternates, then the whole `LibraryList` with Use; "Also on the plan" tick; `swapSessionExerciseFn`. Ticked sets stay as the old lift.
- `SessionFooter`: "x of y sets done" and Finish workout. With 0 ticked it opens `DiscardDialog`. Otherwise `FinishCheckIn`: "How did it go?", effort Easy / OK / Hard / Too much, note (200 chars). With unticked sets: "N of M sets are not ticked. They won't count." plus Keep going; otherwise Skip. Then Save and finish.
- `SummaryDialog` "Workout saved": "N of M sessions this week.", each lift's best set with a trophy for a new best or a "+2.5 kg" change. (The feedback faces here are an account feature.)
- Zen mode (`ZenMode` / `ZenScreen`, full-screen): one exercise and one set pad at a time (name, picture, "N of M"), set dots, big numbers with minus and plus, pill "Set N done" / "Undo set N", reps-left, add / remove set, +1 set to plan, Swap, Previous / Next / Finish, Exit zen, pause clock.

Logic: `nudgeFor`, `stepsOf`, `incrementFor`, `weekdayView`, `weekdayOf`, `lastDoneAt`, `plannedSetsFor`, `weeklyStreakOf`, `activeMs`, `elapsedLabel`, `setPaused`, `suggestNext`, `rampOffer`, `syncEntries`, `swapEntries`, `setsLeft`, `finishSummary`, `shownAlerts`, `stallAlerts`, `bodyweightAlert`, `reviewAlerts`, `nextDayId`, `rollingCursor`.

### `/stats`

Loader `getStatsFn`: finished sessions from the last 365 days with `attachBodyweight`, the last 120 weigh-ins, the last 24 tape entries. Lifts / Sessions / Body ToggleGroup kept in `?tab=` (default lifts).

**Lifts tab:** Strength: trend chips All, Climbing / Stuck / Slipping / Idle / New with counts (`liftTrend`); lift Select (default: most weeks logged); latest weekly best as the big number; a line chart of weekly bests in the day's plate colour (`weeklyStrength`); a table of the last 8 weeks Week / Best set / Change (weight first, reps when the weight held). Recent bests: `recentPRs` over 14 days, up to 8. `liftsFrom` orders lifts: first lift of each day, then the rest of the plan, then dropped lifts.

**Sessions tab:** "This week" / "Week of ...": sessions done "of N sessions" (N = plan day count); "N weeks in a row, effort ok" (`weeklyStreak`, `effortThisWeek`, `effortLabel`); totals "hard sets · kg lifted · min" (`weekTotals`); deload card (`deloadHint`) with "Drop the extra sets on N lifts" (`resetRampFn`). Activity calendar (`monthCalendar`): Monday first, previous / next month, month title opens a dropdown Calendar; days before `joinedAt` and future days disabled; two sessions on a day paint as a split cell (`daySplitStyle`); tapping a day selects its week and opens it: 1 session -> `SessionEditor` (fix sets, add or drop a set, Delete session with confirm, Save changes via `updateWorkoutFn`); 2 or more -> a list; empty earlier day -> the plan days with Log (`draftWorkoutFn`, then `PastSessionEditor` in log mode with Tick all and Log session via `logPastWorkoutFn`); "Back to this week". Hard sets map: `BodyMap` front and back coloured by `regionPaint(done, target)` against `plannedVolumeByMuscle`, each muscle tappable, legend Trained / Planned, not yet / Not in the plan. Export: `ExportButtons` (section 4).

**Body tab:** Bodyweight: latest value, "7-day average X, ±y% vs last week. <paceNote>", "Last logged ..."; Log bodyweight (`LogBodyweightDialog`: weight plus Date picker, no future; same day replaces); chart 4 weeks / 12 weeks / All, tapping a point opens `WeighInDialog` (Save / Remove). Measurements: latest arm, chest, waist; "Last measured ..., N days ago. Next tape day ... / Tape day is due now." (28-day cadence); Log measurements (three fields with `TAPE_HOW` hints, Date); Arm / Chest / Waist switch, 6 months / 1 year / All range; tapping a point opens `TapeDialog`.

## 2. Data model (`src/lib/types.ts`, verbatim)

Constants:
- `DAY_TYPES = ['push','pull','legs','upper','lower','full','chest','back','shoulders','arms','core']` -> `DayType`
- `SPLIT_IDS = ['ppl6','ppl3','pplul5','ul4','phul4','ulf3','full3','bro5','arnold6']`. `SplitId = string`, `PlanSource = string` (a template id or `'custom'`).
- `GOALS = ['gain','hold','cut']` -> `Goal`
- `PROGRESSIONS = ['double','linear','topset']` -> `Progression`
- `MAX_EXERCISES_PER_DAY = 10`, `MAX_DAYS = 14`

Primitive types: `Units = 'kg' | 'lb'`; `Muscle = 'chest'|'back'|'shoulders'|'biceps'|'triceps'|'quads'|'hamstrings'|'calves'|'abs'`; `LoadType = 'weight' | 'bodyweight' | 'time'`; `TrainingAge = 'under1' | 'over1'`; `Schedule = 'rolling' | 'weekday'`; `WorkoutStatus = 'in_progress' | 'done'`; `NudgeKind = 'weight' | 'measure'`.
- `Exercise`: `id; name; sets; repMin; repMax; muscle; loadType; note?; alternates?: string[]; ramp?: { base: number; at: string }`
- `PlanDay`: `id; name; type: DayType; exercises: Exercise[]; weekday?: number` (0 = Sunday to 6)
- `Plan`: `days: PlanDay[]; updatedAt: string`. The server keeps one plan per split slot.
- `Settings`: `units; plate?; dumbbellStep?; stackStep?; sameStep?; bodyweight?; trainingAge; setupDone; joinedAt?; split?; schedule?; progression?; goal?; feedbackAt?; keepAwake?; nudges?: Partial<Record<NudgeKind, NudgeSnooze>>; alertsDismissed?: Record<string, string>; rolledPast?: RollMark`

| Setting           | Default                                                                                                                                                                                                      |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Base              | `DEFAULT_SETTINGS = { units: 'kg', trainingAge: 'over1', setupDone: false }`                                                                                                                                 |
| `split`           | `DEFAULT_SPLIT = 'ppl6'`                                                                                                                                                                                     |
| `schedule`        | `'rolling'`                                                                                                                                                                                                  |
| `progression`     | `'double'` for everyone (the comment in types.ts about linear under a year is stale)                                                                                                                         |
| `goal`            | reads as `'hold'` (setup preselects `'gain'`)                                                                                                                                                                |
| `keepAwake`       | unset means on                                                                                                                                                                                               |
| Steps (`stepsOf`) | plates 2.5 kg / 2.5 lb, dumbbell 2.5 kg / 5 lb, stack 2.5 kg / 5 lb. `STEP_OPTIONS`: plates kg [1.25, 2.5, 5] lb [2.5, 5, 10]; dumbbell kg [2, 2.5, 5] lb [2.5, 5, 10]; stack kg [2.5, 5, 10] lb [5, 10, 15] |
| `alertsDismissed` | pruned after 90 days                                                                                                                                                                                         |
| `bodyweight`      | kept equal to the latest weigh-in by date (`syncSettingsWeight`)                                                                                                                                             |

Smaller shapes: `RollMark { dayId; at }`; `NudgeSnooze { at; times }`; `LoggedSet { weight?; reps?; seconds?; left? (0, 1 = 1-2, 3 = 3+); done }`; `SetTarget { weight?; reps?; seconds? }`.
- `WorkoutEntry`: `exerciseId; name; muscle; loadType; repMin; repMax; hint?; suggested?: SetTarget[]; rampOffer?; equipment?: Equipment; plateLoaded?: true; sets: LoggedSet[]`
- `Workout`: `id; dayId; dayName; dayType; startedAt; finishedAt?; pausedAt?; pausedMs?; status; entries; effort? (1 easy, 2 ok, 3 hard, 4 too much); note?; bodyweight?` (computed by `attachBodyweight`, never stored)
- `BodyweightLog`: `id; date; day? (YYYY-MM-DD); weight` (one per local day; logging again replaces)
- `MeasurementLog`: `id; date; day?; arm?; chest?; waist?` (cm for kg users, in for lb users; same day merges)

Library (`src/lib/library.ts`): `EQUIPMENT = ['barbell','dumbbell','kettlebell','cable','machine','bodyweight']`, `Level = 'beginner'|'intermediate'|'expert'`; `LibraryExercise { id; name; muscle; muscles: string[]; equipment; plateLoaded?; loadType; sets; repMin; repMax; level; cues: string[]; images: string[] }`; `LibraryRow = Omit<LibraryExercise,'cues'>`.

Content (`src/lib/content.ts`): `SplitTemplate { id, name, fit, order, days }`, `SplitInfo { id, name, days: number, fit }`, `Content { library, splits }`.

Looks are not in the data model: per device in `localStorage.theme`.

### Logs export (Stats > Sessions > Export, `ExportButtons`)

A "Sheet layout" toggle (Log | Tracker) with a three-row preview of the first sheet. Buttons: Download Excel, Download CSV (Log only). Data: workouts with `status: 'done'`, limit 5000.

**Log layout, Excel** `plates-logs-YYYY-MM-DD.xlsx`:
- Sets sheet, one row per done set, oldest session first (`setsToRows`). Columns: `Date` (finish day, YYYY-MM-DD), `Time` (start time, HH:MM local), `Day`, `Type`, `Exercise`, `Muscle`, `Set` (1-based), `Weight (kg|lb)` (blank when absent), `Reps`, `Seconds`, `Effort` (Easy / OK / Hard / Too much or blank), `Note`.
- Bodyweight sheet: `Date`, `Weight (kg|lb)`. Date is `day ?? dayKey(date)`; oldest first.
- Measurements sheet: `Date`, `Arm (cm|in)`, `Chest (cm|in)`, `Waist (cm|in)`.

**Log layout, CSV** `plates-logs-YYYY-MM-DD.csv`: the Sets sheet only.

**Tracker layout, Excel only** `plates-tracker-YYYY-MM-DD.xlsx`: one sheet per `dayName` (name drops `[]:*?/\`, cut to 31 chars, " 2" on a duplicate). Columns: `Date`, `Exercise`, `Sets` (count done), `Weight (units)` (one number if every set used the same weight, else "a / b / c"), `Set 1` ... `Set N` (reps, or "45 s" for a hold; N = most done sets of any lift that day), `Total reps`, `Effort`, `Note`. One row per lift per session; lifts with no set done left out. Then the Bodyweight and Measurements sheets.

### Plan template download (`planWorkbook` in `src/lib/plan-workbook.ts`)

- File: `plates-template-<splitId>.xlsx`, or `plates-template.xlsx` for a custom plan.
- Plan sheet, headers `TEMPLATE_HEADERS`: `Day, Type, Exercise, Sets, Reps, Load, Muscle, Note, Alternates`. One row per exercise, day name repeated on every row (`planToRows`). Reps reads "6-10", "12", or "30-45 s". Load is `weight|bodyweight|time`. Alternates joined with ", ". Reps column forced to text (`t:'s'`, `z:'@'`) for the plan rows plus 40 more. Column widths 10, 7, 30, 6, 9, 11, 11, 40, 40.
- Guide sheet: optional first line from `templateTitle` ("Template: <name>, N days (<id>)"), then `GUIDE_LINES`:
  1. How to fill the Plan sheet
  2. One row per exercise. Keep the header row as it is.
  3. Day: the session name, like Push A. Leave it blank on following rows to keep the same day.
  4. Type: one of push, pull, legs, upper, lower, full, chest, back, shoulders, arms, core. Blank is fine, it is guessed from the day name.
  5. Exercise: the name you want to see in the app.
  6. Sets: a whole number, like 4.
  7. Reps: a range like 6-10, a single number like 12, or seconds for holds like 30-45 s.
  8. If Excel turns 6-10 into a date, type an apostrophe first: '6-10
  9. Load: weight, bodyweight or time. Blank is fine, it is guessed from the name.
  10. Muscle: one of chest, back, shoulders, biceps, triceps, quads, hamstrings, calves, abs. Blank is fine, it is guessed from the name.
  11. Note: a short cue. Alternates: other exercises for the same slot, separated by commas.
  12. Upload the file on the Bring your own plan page. Nothing is stored until you confirm.
- Template sheet (template plans only; `templateMarker`): rows `[Split, <id>]`, `[Name, <name>]`, `[Days, <n>]`.

### Plan import (upload), parser rules in `plan-sheet.ts`

Reading: accepts `.xlsx/.xls/.csv`; SheetJS reads with `cellDates: true, raw: true`; uses the sheet named `Plan`, else the first; rows via `sheet_to_json` with header keys and `defval: ''`. Marker: cells of the `Template` and `Guide` sheets go to `splitFromMarker(cells, knownIds)` (a "Split" cell followed by a known id, or a cell ending in "(id)"). A CSV never has a marker, so it imports as custom.

Header aliases (lower-cased, non-letters stripped), first match wins:

| Column     | Accepted headers                                 |
| ---------- | ------------------------------------------------ |
| day        | day, dayname, session, workout                   |
| type       | type, daytype                                    |
| exercise   | exercise, exercises, name, movement, lift        |
| sets       | sets, set                                        |
| reps       | reps, rep, reprange, range                       |
| repmin     | repslow, low, min, repmin                        |
| repmax     | repshigh, high, max, repmax                      |
| load       | load, loadtype, kind                             |
| muscle     | muscle, musclegroup, bodypart                    |
| note       | note, notes, cue, cues                           |
| alternates | alternates, alternate, alternatives, swaps, swap |

Row rules: warnings use index + 2; a blank row is skipped silently; a Day cell starts a new day or reuses a same-named day (case-insensitive), a blank Day continues the current day; day id `slug(name)` made unique; Type via `parseDayType` (exact or prefix) else `guessDayType(name)` (order full, upper, lower, arms / bicep / tricep, shoulder / delt, chest, core / abs, pull, back, leg / squat / deadlift / glute; fallback push); no exercise name -> "No exercise name, row skipped."; no day above -> "No day name above this row, row skipped."; Sets `parseInt`, invalid or below 1 -> 3 with "Sets missing for X, used 3.", capped 10; Low / High columns win, else `parseReps` ("6-10", "12", "45-60 s", "10 each leg"), a Date cell is turned back into month-day with "Reps for X looked like a date. Read it as m-d. Check it.", missing -> 8-12 with "Reps missing for X, used 8-12.", capped 600; Load via `parseLoad` (weight / weighted / loaded / barbell / dumbbell / machine / cable -> weight; bodyweight / body weight / bw / calisthenic -> bodyweight; time / timed / hold / seconds / sec / isometric -> time) else `guessLoad(name, repsText)`; Muscle via `MUSCLE_ALIASES` (pecs, lats, delts, hams, glutes -> hamstrings, legs -> quads, core -> abs) else `guessMuscle(name, dayType)` else `MUSCLE_BY_DAY[type]`; Note cut to 200, Name to 80; Alternates split on `, ; |`, at most 10; exercise ids slugs unique within the day; days with no exercises dropped; nothing left -> row 0 "No exercises found. Check the header row and the Exercise column." `parseRows` never throws.

Before "Use this plan": at least 1 day; every day named with 1 to 10 exercises; every exercise named; sets >= 1; 1 <= repMin <= repMax. On confirm: `replacePlanFn({ days, split })`; `settings.split` becomes the marker's id or `'custom'`. Logged workouts stay. The next session starts from day one.

### Import of past sessions or logs?

No. The only file input is the plan page. No route reads `everything.json`, `sessions.csv`, the tracker workbook, weigh-ins or tape back in. Past sessions are added by hand on the Stats calendar only.
